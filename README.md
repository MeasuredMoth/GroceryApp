
# Grocery App (Name Pending)

Grocery App is a phone application to streamline the process of creating, and maintaining a weekly or monthly meal plan. Focused on building around buying groceries for your planned meals to reduce food waste and spending.

## Run Locally

Install dependencies

```bash
  npm install
```

## Running Tests

To run tests, run the following command. All tests are contained in `__test__`.

```bash
  npx jest
```

To run the web app locally, run the following command.

```bash
  npx expo
```
